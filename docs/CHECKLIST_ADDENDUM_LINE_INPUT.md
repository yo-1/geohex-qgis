## H05・H06: 公式GeoHex v3.2 JSとの比較（結果報告）

既存チェックリスト9章「H: GeoHex互換性」のH05・H06について、以下のとおり実施済み。

| ID | 検証 | 結果 |
|---|---|---|
| H05 | GeoHex v3.2公式JSとの比較 | ☑ 一致（920件、不一致0件） |
| H06 | 複数地点・複数Levelで公式JS比較 | ☑ 実施済み |

**手順**（再現可能な形で記録）:
1. `http://geohex.net/src/script/hex_v3.2_core.js` から公式JSソースを取得。
2. Node.js の `vm.runInThisContext` でこのファイルをグローバルスコープで実行し、`GEOHEX.getZoneByLocation` / `getZoneByCode` / `getHexCoords` をそのまま呼び出す（アルゴリズムを読み替えず、公式コードの実行結果そのものを使用）。
3. 固定代表点（日本国内の主要都市・最南端/最北端、世界の主要都市、日付変更線付近、極付近、計20地点）× Level 0, 3, 7, 9, 11, 15、および日本域・世界域の疑似乱数点（各300点、Level 0〜15）の合計920件で、公式JSの出力（`code`, `x`, `y`, 中心緯度経度, `getHexCoords`の6頂点, decode結果）を生成。
4. 本リポジトリの `geohex_generator/geohex_v3.py`（Pythonポート）で同じ入力を処理し、全項目を数値許容誤差 `1e-9`（度）で比較。
5. **結果: 920件すべて一致（不一致0件）。**

このうち代表的な24地点・Levelの組み合わせを `tests/test_geohex_v3.py` の `OfficialJSCrossValidationTest` に固定の期待値として埋め込み、Node.js非依存の回帰テストとして恒久化した（PR化予定）。全920件を再生成するスクリプト自体はリポジトリに含めていないため、再度フルセットでの確認が必要な場合は、上記手順を再実行すればよい。
