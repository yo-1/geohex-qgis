| ID | 検証内容 | 期待結果 | 結果 |
|---|---|---|---|
| L01 | 路網レイヤ（例: kanagawa_allroad）でLevel 5を実行 | 正常終了。抽出条件は常に『重なるセル』で処理される | ☐ |
| L02 | 路網レイヤでLevel 6を実行 | 正常終了 | ☐ |

| L10 | 自己交差など無効な形状を含むラインレイヤで実行 | クラッシュしない。ラインジオメトリは自動修復の対象外である点を確認する（ポリゴンのみ修復対象） | ☐ |
